# Museum — Landing Page

This project is a modern and responsive landing page for a Museum. It is designed to provide users with an immersive experience, showcasing exhibitions, historical information, and ticket booking options with a clean and engaging user interface.

## Live Preview

Experience the live website here: [Museum Landing Page Demo](https://svyatoslav1313.github.io/landing-page-museum/)

## Design Reference

The project was developed based on a professional Figma design to ensure high-quality UI and UX standards.

## Technologies Used 💻

### Core

- **HTML5** — Semantic structure
- **SCSS / CSS** — Advanced styling and layouts
- **JavaScript** — Interactive components and logic

### Methodology & Tools

- **BEM (Block Element Modifier)** — For clean and maintainable CSS
- **Git/GitHub** — Version control and deployment
- **VS Code** — Development environment

## Setup Instructions

Follow these steps to set up the project locally:

1. **Clone the repository:**

```bash
git clone https://github.com/svyatoslav1313/landing-page-museum.git
cd landing-page-museum
```

2. **Install dependencies:**

```bash
npm install
```

3. **Run the project locally**

```bash
npm start
```

## Features

- **Responsive Design:** Optimized for different screen sizes and devices (Mobile, Tablet, Desktop).
- **Interactive Gallery:** Showcasing museum exhibits with smooth hover effects.
- **Navigation:** Easy access to different sections.
- **Scroll to Top Button:** Easily return to the top of the page.
